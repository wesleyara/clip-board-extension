Ajuda

Criar um clip

  1. Clique no + no canto superior direito.
  2. Digite o texto no campo Novo clip. Espaços extras são removidos ao salvar.
  3. Opcional: selecione uma ou mais tags.
  4. Clique em Salvar. Para descartar, use Cancelar.

Tags

  • Criar: digite o nome em Criar nova tag e clique em + ou pressione Enter.
  • Selecionar: clique em uma tag para marcá-la ou desmarcá-la no clip. Tags marcadas ficam destacadas.
  • Remover: clique no × ao lado da tag. Ela é retirada de todos os clips.
  • Limpar filtro: use o botão de borracha ao filtrar por tag para desmarcar todas.

Buscar e filtrar

  • Buscar: digite no campo Buscar clips. A lista mostra apenas os clips que contêm o texto.
  • Todos: mostra todos os clips.
  • Favoritos: mostra só os clips com estrela.
  • Por tag: mostra as tags disponíveis. Escolha uma ou mais e use o modo Contém uma tag (qualquer uma) ou Contém todas tags (todas ao mesmo tempo).

Ações em cada clip

  • ★ Favoritar: marca ou desmarca o clip como favorito.
  • Copiar: copia o texto para a área de transferência.
  • Editar: abre o formulário com o texto e as tags do clip. Clique em Salvar para atualizar.
  • Remover: apaga o clip depois de uma confirmação.

Variáveis

Use {{NOME}} no texto do clip. Ao copiar, um popup pede o valor de cada variável e o texto preenchido é copiado. O clip salvo não muda.

Exemplo: Olá {{NOME_PESSOA}}! Você atende em {{NOME_CIDADE}}?

Reordenar

Arraste um clip e solte sobre outro para trocar a ordem.

Exportar e importar

  • Exportar: baixa um arquivo .json com todos os seus clips, tags e favoritos.
  • Importar: escolha um .json exportado antes. Clips com o mesmo texto ou o mesmo ID já existentes são ignorados. Os demais são adicionados, sem apagar nada.

Onde ficam os dados

Seus clips são salvos localmente no navegador, pela própria extensão. Use Exportar para fazer backup.
